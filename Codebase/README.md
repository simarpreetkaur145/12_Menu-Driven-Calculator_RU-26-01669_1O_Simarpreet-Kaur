# Menu-Driven Calculator

## 1. Project Description

The Menu-Driven Calculator is a console-based application developed using Python. It allows users to perform different arithmetic operations by selecting an option from a menu.

The program continues displaying the menu until the user chooses the Exit option.

## 2. Features

- Addition
- Subtraction
- Multiplication
- Division
- Power
- Modulus
- Input validation
- Handles division by zero
- Handles modulus by zero
- Displays results up to two decimal places
- Repeated menu until the user exits

## 3. Available Operations

| Choice | Operation |
|---|---|
| 1 | Addition |
| 2 | Subtraction |
| 3 | Multiplication |
| 4 | Division |
| 5 | Power |
| 6 | Modulus |
| 7 | Exit |

## 6. Error Handling

The program handles the following situations:

- Non-numeric input
- Division by zero
- Modulus by zero
- Invalid menu choices

Appropriate error messages are displayed to guide the user.

## 7. How to Run the Project

1. Install Python 3.
2. Download or clone this repository.
3. Open the Codebase folder.
4. Open the terminal in that folder.
5. Run the following command:

   `python Menu-Driven-Calculator.py`
